# Zeal legacy profile example

This directory preserves repository-specific knowledge removed from the portable
functional audit during Phase 0. It is an example only: paths and checks are not
executed from this repository and do not claim that the target application is
currently available.

Before using these materials, copy and validate them in the target application's
own `audits/project-profile/` directory. The target must supply its real commands,
fixtures, database adapter, deployment adapter, and ownership metadata.
